## 🕹️ 操作

### 手机（竖屏 · 主要玩法）

屏幕底部三个大按键（**92px**，拇指友好）：

```
        [🅿️]         ← 手刹（可换到左边）
                  ← 上方留空，拇指上移即可

 [◀]     [▲]     [▶]
 左转    起步     右转
```

- **起步键是绿色的**，自动加速不用一直按
- **手刹键可换位置**（设置里选左或右）

### 键盘

| 功能 | 玩家 1 | 玩家 2 |
|---|---|---|
| 左转 | `A` | `←` |
| 右转 | `D` | `→` |
| 手刹 | `S` | `↓` |
| 起步喷 | `W` | `↑` |
| 切视角 | `1` `2` `3` | |
| 重开 | `R` | |

## 🔥 核心机制

### 起步喷（Launch Boost）
倒计时 **4 → 3 → 2 → 1 → GO**，在倒计时期间按 `W`：

| 按下时机 | 效果 |
|---|---|
| 剩 ≤1.2s（压哨）| **PERFECT** +55% 推力 |
| 剩 ≤2.4s | GOOD +22% |
| 太早 | 打滑（-38%）|

### 漂移
- 高速入弯**自动起漂**
- 左右反打方向可救车
- **连漂加分**（右上角 DRIFT 计分板）

### 加速带 ⚡
路面上的**橙色发光箭头带**，踩中：
- 瞬间提速 +32%
- 持续 1.2 秒推力
- 屏幕震动 + 橙色光晕

### 撞飞
| 情况 | 结果 |
|---|---|
| 高速追尾 NPC | **NPC 被撞飞**翻滚，自己只减速 |
| 逆行撞对向车 | **自己被甩飞**（重装坦克免疫）|

### 跳台
冲上坡道**腾空飞行**（速度越快飞越高），落地**扬尘致盲 2 秒**。

### 其他
- **隧道**：内部变暗 + 拱门 + 回声
- **桥涧**：桥面 + 栏杆 + 下方深渊
- **闭环缓冲**：跨圈无缝衔接，无断层
- **行人**：弯道外侧聚集，撞到会倒地 + 番茄汁

## 🚀 本地运行

```bash

cd turbo-game

# 方式一：直接双击 index.html
# 方式二：起个服务（体验 PWA 离线需要 http）

```

## 🛠️ 技术

- **单文件 HTML**，零依赖、零构建、零框架
- **Canvas 2D 伪 3D**：分段透视投影 + 雾效 + 地平线视差
- **WebAudio 程序化音频**（无任何音频文件）：
  - 引擎声（锯齿波 + 低八度叠加）
  - BGM（Am-F-C-G 和弦 + 鼓组 + 贝斯，~130 BPM）
  - 音效（漂移 / 碰撞 / 起步喷 / 番茄汁 / 倒计时）
- **自研轻量 i18n + 主题系统**
- **Service Worker** 网络优先缓存
