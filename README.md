## 🕹️ 操作

### 手机（竖屏 · 主玩法）

```
              [🅿️]        ← 手刹（可在设置里换到左边）
           （上方留空，拇指上移即可）

  [◀]         [▲]        [▶]
  左转        起步        右转
```

- **起步键绿色**，自动加速不用一直按
- **手刹默认在右转上方**，左撇子可在设置里换到左侧（完全镜像）

### 键盘

| 功能 | 玩家 1 | 玩家 2 |
|---|---|---|
| 左转 | `A` / `←` | `←` |
| 右转 | `D` / `→` | `→` |
| 手刹 | `S` / `↓` | `↓` |
| 起步喷 / 氮气 | `W` / `↑`（倒计时按住=起步喷，比赛中点一下=放氮气） | `↑` |
| 切视角 | `1` `2` `3` |
| 重开 | `R` |

## 🔥 核心机制

### 起步喷
倒计时 **4 → 3 → 2 → 1 → GO**，期间按 `W`：

| 时机 | 效果 |
|---|---|
| 剩 ≤1.2s（压哨）| **PERFECT** +55% |
| 剩 ≤2.4s | GOOD +22% |
| 太早 | 打滑 -38% |

### 漂移
高速入弯自动起漂 · 反打方向救车 · 连漂加分

### 加速带 ⚡
橙色发光箭头带：瞬间 +32% · 持续 1.2s · 屏幕震动 · 顺带 +半格气

### 账号 / 金币 / 解锁 💰

第一次打开会自动生成一个**六位 ID**（如 `APTMUH`），存档全部存在本地，首页点 ID 条可看：

| 项 | 说明 |
|---|---|
| 金币 | 完赛结算发放，**一局 20~60**（距离 / 漂移 / 少撞车加成） |
| 存档码 | 档案面板里「复制存档码」，换手机粘过去点「导入」即可整套搬走 |
| 彩蛋 | 存档码框里输入 **`YYDS`**（大小写都认）→ 直接满级：999999 币 + 全车 + 全场地 + 全车漆 |
| 赛车 | 街头小子 免费 · 赛道猛兽 1200 · 漂移之王 1800 · 重装坦克 2500 |
| 场地 | 黄昏海岸 免费 · 午夜都市 800 · 雪原山口 1200 · 荒漠公路 1800 · 自定义 2200 |
| 3D | 入口免费；3D 车库里的车漆用金币解锁（薄荷 免费 / 紫电 1500 / 赤金 3000） |

3D 和 2D 共用同一份档案（同一个 localStorage key），金币、ID、车漆都互通。

### 集气氮气 🔥
漂移 / 加速带 / 完美起步都会攒气，最多 3 格：

| 动作 | 集气 |
|---|---|
| 漂移 | 每秒约 +0.55 格（漂得越狠越快）|
| 加速带 | +0.55 格 |
| 完美起步 | +0.9 格 |

**点一下加速键**（手机点 ▲ / 键盘点 `W`/`↑`）放 1 格：2 秒内极速 ×1.35、蓝色尾流、轻微震屏。
松开/时间到自动结束，剩下的气保留。

### 撞飞
| 情况 | 结果 |
|---|---|
| 追尾 NPC | NPC 翻滚飞出去 |
| 逆行撞对向 | **自己被甩飞**（重装坦克免疫）|

## 🎮 逆反 3D（正式版 v8）

真 3D（three.js r160，已本地化），手机竖屏单手可玩。**没有技能系统**，节奏改成「跑圈捡金币 → 解锁车漆」。

### 玩法

- **自动油门**：不用管油门，专心打方向（和 2D 一致）
- **智驾 / 手动**：右上角一键切换。智驾 = 自动走内线 + 提前避让 NPC，按方向键可随时接管
- **氮气**：漂移集气（最多 3 格）→ 点 `N₂` / Shift 放一格，每格 2 秒、极速 ×1.35
- **金币**：赛道上撒 24 枚，每枚 3 币；完赛另有奖励。金币和 2D 共用同一份存档
- **三视角**：跟随 / 车头（第一人称）/ 远景，`C` 或暂停面板切换
- **起跑**：车停在起跑线**后面**，前方 4 米是黑白格起跑线，25 米处是起跑门架
- **设置**（暂停面板）：音效、黄昏/白天主题、陀螺仪、视角

## 🚀 本地运行

```bash
git clone https://github.com/gcy529/turbo-game.git
cd turbo-game

# 方式一：双击 index.html 直接玩
# 方式二：起个服务（PWA 离线需要 http）
python -m http.server 8000
# 打开 http://localhost:8000
```

## ☁️ 部署到你自己的平台

### Cloudflare Pages（推荐，免费且稳）
```bash
npm i -g wrangler
wrangler pages deploy . --project-name=turbo-game
```
或直接在 CF Dashboard 连 GitHub 仓库，构建命令留空，输出目录 `/`。

### Netlify
```bash
npm i -g netlify-cli
netlify deploy --prod --dir=.
```
`netlify.toml` 已配好，直接拖文件夹到 Netlify Drop 也行。

## 🛠️ 技术

- **单文件 HTML**，零依赖、零构建、零框架
- **Canvas 2D 伪 3D**：分段透视投影 + 雾效 + 地平线视差
- **Three.js r128**：真 3D 赛道 + 动态光影（3D 版）
- **WebAudio 程序化音频**（无任何音频文件）
  - 引擎声（锯齿波 + 低八度叠加）
  - BGM（Am-F-C-G + 鼓组 + 贝斯，130 BPM）
  - 音效（漂移 / 碰撞 / 起步喷 / 番茄汁 / 倒计时）
- **自研 i18n + 主题系统**
- **Service Worker** 网络优先缓存
