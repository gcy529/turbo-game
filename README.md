# 极速狂飙 Turbo Game 🏁

> 纯前端伪 3D 赛车游戏 · 单文件零依赖 · 手机竖屏可玩 · PWA 离线

**🎮 立即开玩：https://gcy529.github.io/turbo-game/**

## 特色

| 玩法 | 说明 |
|---|---|
| 🏎️ **4 辆赛车** | 街头小子 / 赛道猛兽 / 漂移之王 / 重装坦克，属性各异 |
| 🗺️ **4 张地图 + 自定义** | 黄昏海岸 / 午夜都市 / 雪原山口 / 荒漠公路，或自己规划赛道并命名 |
| 🌦️ **天气系统** | 晴 / 雨（打滑）/ 雾（低能见度）/ 夜（车灯视角），影响物理与视野 |
| 👁️ **三种视角** | 远景 / 中景 / 第一视角（带方向盘与仪表台） |
| 🌗 **日夜主题** | 深色 / 浅色界面，一键切换 |
| 🌐 **中英双语** | 全界面中文 / English 切换 |
| 🤖 **自动驾驶示范** | AI 跑完美路线，供学习走线 |
| 🏆 **排行榜** | 本地存储各图最佳圈速 |
| 📱 **PWA** | 手机可「添加到主屏幕」，离线可玩 |

## 操作

### 手机（竖屏）
屏幕下方三个大按钮：**◀ 转向 ▶** + **▲ 加速/刹车**

### 键盘
| | 玩家 1 | 玩家 2 |
|---|---|---|
| 左转 | `A` | `←` |
| 右转 | `D` | `→` |
| 刹车 / 后退 | `S` | `↓` |
| 起步喷 | `W` | `↑` |

> **自动挡**：松开也自动加速；**手动挡**（设置里开）：必须按住。

## 核心机制

- **起步喷**：倒计时快结束按加速键 → PERFECT（+55% 推力）/ GOOD / 早踩打滑
- **漂移**：高速入弯自动起漂，反打方向救车，连漂加分
- **加速带**：路面橙色发光箭头带，踩中瞬间提速 + 屏幕震动
- **撞飞**：高速追尾把 NPC 撞飞翻滚；逆行撞对向车则自己被甩飞
- **跳台**：冲上坡道腾空飞行，落地扬尘致盲 2 秒
- **隧道 / 桥梁**：隧道内变暗带回声，桥梁下方是深渊

## 本地运行

下载 `index.html` 双击即可（无需服务器、无需构建）。

```bash
git clone https://github.com/gcy529/turbo-game.git
cd turbo-game
# 直接打开 index.html，或
python -m http.server 8000   # 体验 PWA 离线功能需 http(s)
```

## 技术

- 单文件 HTML（~165KB），零依赖、零构建、零框架
- Canvas 2D 伪 3D 渲染（分段投影 + 雾效 + 视差背景）
- WebAudio 程序化音效（引擎 / 漂移 / 碰撞 / BGM 全部实时合成，无音频文件）
- 自研轻量 i18n + 主题系统
- Service Worker 离线缓存
